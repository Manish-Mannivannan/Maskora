# Maskora

A local desktop application for inspecting how printed artwork looks after spot UV, raised UV and other
finishing processes. Open a production PDF, map finishing masks to artwork, and inspect the result under
adjustable light. Documents never leave the computer.

The canonical architecture and implementation plan live in the maintainer's Obsidian vault
(`Obsidian/Projects/Maskora/`); this README covers operating the repository. The plan is mirrored to this
repository's GitHub milestones and issues.

## Stack

Tauri 2 (Rust native services) with a Next.js static-export interface in React and TypeScript, rendering with
Three.js, React Three Fiber and Drei, and PDF.js for PDF reading. Exact versions are in
[VERSIONS.md](VERSIONS.md). Windows (WebView2) is the only verified platform.

## Prerequisites

- Node.js 24 (24.3.0 or later in the 24 line) and npm 11
- Rust via rustup; `rust-toolchain.toml` selects the pinned toolchain automatically
- Microsoft C++ Build Tools and the WebView2 runtime (Tauri's Windows prerequisites)
- [graphify](https://pypi.org/project/graphifyy/) for the codebase map: `uv tool install graphifyy`
- The GitHub CLI, signed in, only for mirroring the plan (`npm run plan:issues`)

## Setup

```powershell
npm run setup
```

Installs exact dependency versions from `package-lock.json`, points git at the tracked hooks in `.githooks/`,
registers graphify's merge driver for `graphify-out/graph.json`, and fetches Rust crates. Re-runnable.

## Run

```powershell
npm run tauri dev
```

Starts `next dev` on `http://localhost:3000` and opens the Maskora window on it.

## Check

```powershell
npm run check
```

Runs, in order: the secret scan and ADR-citation check, Prettier, ESLint, TypeScript, the Vitest suite
(including the fixture determinism check), and `cargo fmt`, `clippy -D warnings` and `cargo test` for
`src-tauri`. The pre-push hook runs the same command; the pre-commit hook runs the convention checks.

## Build

```powershell
npm run tauri build
```

`next build` writes the static export to `out/`, which Tauri bundles into the installer under
`src-tauri/target/release/bundle/`.

## Fixtures

Synthetic PDFs and their expected values are generated by `node tests/fixtures/generate.mjs`; see
[tests/fixtures/README.md](tests/fixtures/README.md). No real or customer document is ever committed.
